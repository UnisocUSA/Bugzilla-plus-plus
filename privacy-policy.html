Privacy Policy

BugZilla++ Chrome Extension  ·  Effective date: February 18, 2026  ·  Last updated: February 18, 2026

1. Introduction

This Privacy Policy describes how the BugZilla++ Chrome browser extension ("the Extension", "we", "our") handles information when you use it. We are committed to protecting your privacy. This policy complies with the Chrome Web Store Developer Program Policies and applicable privacy laws including GDPR and CCPA.

Summary: BugZilla++ does not collect, transmit, sell, or share any personal data. All processing happens locally in your browser.

2. Information We Do Not Collect

The Extension does not collect, record, store on our servers, or transmit to any third party any of the following:

  • Personal identifiable information (name, email address, IP address, etc.).
  • Browsing history, bug IDs, comment content, or attachment data.
  • Usage statistics, analytics, or crash reports.
  • Cookies or tracking data of any kind.

We do not operate any servers, databases, or analytics pipelines associated with this Extension.

3. Information Stored Locally on Your Device

The Extension uses the Chrome storage.sync API solely to persist your personal preferences across browser sessions. This data never leaves your Google Account's sync storage and is never accessed by us. The data stored includes:

  • Dark-mode preference (enabled/disabled).
  • Per-username colour mappings you configure in the Options panel.
  • UI section collapsed/expanded states.

You can clear this data at any time by removing the Extension or clearing Chrome's extension storage via chrome://settings/clearBrowserData.

4. Network Requests

When you open an attachment preview, the Extension fetches that attachment directly from the Bugzilla instance you are already authenticated with — using your existing browser session, exactly as clicking the link yourself would. No attachment data is forwarded to any external server.

The Extension does not contact any domain other than the Bugzilla host currently open in your browser. All third-party library code (PDF.js, SheetJS, JSZip) is bundled inside the Extension package; no requests are made to CDNs or external servers.

5. Permissions Explained

Permission Why it is needed
storage Save your theme and colour preferences across browser sessions using Chrome Sync.
activeTab Read the URL of the currently active tab to determine whether it is a Bugzilla page.
scripting Inject the UI enhancement scripts and stylesheet into Bugzilla pages.
host_permissions: *://*/* Bugzilla is self-hosted software with no fixed domain. The wide host permission lets the Extension work on any Bugzilla installation. It is used only to inject content scripts and proxy attachment fetches back to the same origin — never to access unrelated sites.

6. Use of Third-Party Libraries

The Extension bundles the following open-source libraries locally (no CDN or external requests are made):

  • PDF.js (Mozilla Foundation, Apache 2.0 licence) — in-browser PDF rendering.
  • SheetJS (xlsx) (Apache 2.0 licence) — spreadsheet preview (XLS/XLSX).
  • JSZip (MIT licence) — ZIP file browsing and in-browser extraction.

None of these libraries make independent network requests or collect user data.

7. Data Security

Because the Extension does not collect or transmit personal data, there is no data at risk of unauthorised disclosure. Your Bugzilla session credentials are managed entirely by your browser and the Bugzilla server; the Extension never reads or stores them.

8. Children's Privacy

The Extension is designed for use in professional software-development environments. It is not directed at children under the age of 13, and we do not knowingly collect any information from children.

9. Changes to This Policy

If this policy is updated, the "Last updated" date at the top of this page will be revised. Significant changes will also be noted in the Chrome Web Store release notes for the corresponding version. Continued use of the Extension after an update constitutes acceptance of the revised policy.

10. Contact

For questions or concerns about this privacy policy, please open an issue on the GitHub repository or contact the maintainers listed there.
