Privacy Policy

Bugzilla++ Browser Extension  ·  Effective date: March 26, 2026  ·  Last updated: April 12, 2026

1. Introduction

This Privacy Policy describes how the Bugzilla++ browser extension ("the Extension") collects, handles, stores, and shares user data. We are committed to protecting your privacy and being transparent about what data flows where. This policy complies with the Chrome Web Store Developer Program Policies and applicable privacy laws including GDPR and CCPA.

Key principle: Bugzilla++ does not operate any servers, databases, or analytics pipelines. It does not collect any personal data itself. All features that communicate with external services are disabled by default and only activate when you explicitly enable them. Core features (dark mode, attachment previews, sorting, timestamps) work entirely offline with zero network requests beyond the Bugzilla page you are already viewing.

2. Information We Collect

The Extension collects and processes the following categories of data, depending on which features you have enabled. No data is collected unless you interact with the corresponding feature.

2.1 Data collected automatically (Tier 1 — Fully Local)

When you visit a Bugzilla page with the Extension enabled, the following data is processed entirely within your browser and is never transmitted anywhere:

  • Page content: Bug titles, comment text, attachment metadata, and field values are read from the Bugzilla page DOM to render UI enhancements (dark mode, previews, timestamps, color coding). This data is never copied or sent outside your browser.
  • Attachment file contents: When you click to preview an attachment, the file is fetched from the Bugzilla server you are already authenticated with — exactly as clicking the attachment link yourself would. Previews are cached locally in your browser.
  • Recently visited bugs and searches: Bug IDs, titles, and search queries you visit are stored locally for the recent-bugs dropdown. This data stays on your device.
  • User preferences: Theme choice, accent colors, language, and feature toggles are stored in chrome.storage.sync (synced across your signed-in Chrome browsers via your Google Account).

2.2 Data collected with your explicit action (Tier 2 — Corporate Directory)

These features activate only when your organization's corporate directory is accessible, and you interact with employee-related UI elements:

  • Employee directory data: When you hover over a commenter's email, the Extension fetches their name and photo from the company directory. This is the same directory data visible in your corporate email client. Results are cached locally in your browser.

No personal data leaves the corporate network. These requests go to internal servers your browser already has access to. If you are not on a corporate network with a supported directory, these features are hidden and inactive.

2.3 Data collected when you enable AI features (Tier 3 — Off by Default)

AI-powered translation and summarization features are completely disabled until you explicitly select an AI model in Settings. When enabled:

  • Bug comment text is sent to the AI service you selected for translation and/or summarization. Only the text content of comments is sent — no credentials, attachments, file contents, or personally identifying metadata.
  • OpenRouter API key: If you enter an OpenRouter API key, it is stored in chrome.storage.sync (encrypted by your Google Account). The key is sent only to openrouter.ai for authentication.

2.4 Information we do NOT collect

The Extension does not:

  • Collect usage statistics, analytics, telemetry, or crash reports
  • Track your browsing history or set cookies
  • Record, store, or transmit your Bugzilla login credentials or passwords
  • Access data on non-Bugzilla websites
  • Collect any data from children under 13 years of age

3. How We Handle Your Data

All data processing occurs locally in your browser. The Extension does not operate any servers, backend systems, or databases. Specifically:

  • Page content is read from the DOM, enhanced visually, and displayed back to you. It is never copied to any external service (unless you have enabled AI translation).
  • Attachment files are fetched directly from the Bugzilla server using your existing authenticated session. They are decoded and rendered in-browser.
  • Employee data (when available) is fetched from your corporate directory and cached locally to reduce repeated lookups.
  • AI translations are cached locally after the first request so the same comment text is never sent to the AI service twice.

4. How We Store Your Data

All data is stored locally in your browser using standard browser APIs. The Extension does not store any data on external servers.

You can delete all stored data at any time by:

  • Using the "Clear ALL caches" button in Settings
  • Using the "Reset to Defaults" button in Settings
  • Removing the Extension from your browser
  • Clearing your browser's extension storage via Chrome settings

5. How We Share Your Data

We do not sell, rent, trade, or share your data with any third parties.

The only circumstances in which data leaves your browser are:

  • Bugzilla server requests: Attachment file downloads and page requests go to the Bugzilla server you are already authenticated with. This is identical to normal Bugzilla usage without the Extension.
  • Corporate directory lookups: If your organization's directory is accessible, employee name and photo lookups are made to internal servers your browser already has access to.
  • AI translation (opt-in only): When you explicitly enable an AI model, comment text is sent to the selected AI service as described in Section 2.3. No data is sent to any AI service unless you have opted in.

The Extension does not contain any advertising, tracking pixels, or analytics scripts. No data is shared with the Extension's developers, distributors, or any other party.

7. Third-Party Services and Libraries

7.1 Third-party services

The Extension may communicate with these third-party services only when you have explicitly opted in:

  • OpenRouter (openrouter.ai) — AI translation, when you select an OpenRouter model and provide an API key. Governed by OpenRouter's own privacy policy.

All other external communication goes to servers you already have access to (your Bugzilla instance, your corporate directory).

7.2 Bundled open-source libraries

The Extension bundles the following libraries locally. No CDN or external requests are made — all code ships inside the extension package:

  • SheetJS (xlsx) (Apache 2.0) — spreadsheet preview
  • JSZip (MIT) — ZIP file browsing
  • Tiptap (MIT) — Markdown WYSIWYG editor
  • highlight.js (BSD-3-Clause) — syntax highlighting
  • Slim Select (MIT) — searchable dropdown replacement
  • bzip2.js (MIT) — Bzip2 decompression

None of these libraries make independent network requests or collect user data.

8. Data Security

Since the Extension does not collect personal data or operate servers, the primary security measures are:

  • All network communication uses HTTPS.
  • Your Bugzilla session credentials are managed by your browser — the Extension never reads, stores, or transmits passwords or session cookies.
  • OpenRouter API keys stored in chrome.storage.sync are encrypted by your Google Account.
  • All locally cached data is accessible only to the Extension within your browser profile.
  • All extension code is unminified and auditable.

9. Your Rights

Because the Extension stores all data locally on your device and does not maintain any server-side records, you have full control over your data at all times:

  • Access: All stored data is visible in Chrome's extension storage inspector.
  • Deletion: Use "Clear ALL caches" in Settings, "Reset to Defaults," or simply remove the Extension.
  • Portability: Your preferences sync via your Google Account through chrome.storage.sync.
  • Opt-out: Disable any feature tier independently — turn off AI by setting the model to "None"; corporate features deactivate automatically outside your corporate network.

If you are located in the European Union, you may exercise additional rights under the GDPR. Since we do not collect or process personal data on any server, there is no server-side data to request access to or deletion of.

10. Children's Privacy

The Extension is designed for use in professional software-development environments. It is not directed at children under the age of 13, and we do not knowingly collect any information from children. If you believe a child has provided data through this Extension, please contact us so we can address the concern.
